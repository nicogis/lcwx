Lite Card Wallet eXpress

Guida rapida per aggiungere, gestire e mostrare le tue carte fedeltà in modo semplice. Qui trovi le operazioni principali, le domande più frequenti e alcune note utili.

Perché è stata creata questa app

Lite Card Wallet eXpress nasce con un'idea semplice: offrire un portafoglio carte leggero, privato e senza complicazioni.

  • Nessun account: non serve registrarsi.
  • Nessuna pubblicità: esperienza pulita e senza distrazioni.
  • Gratuita: tutte le funzioni disponibili senza costi.
  • Nessun servizio esterno: niente cloud o dipendenze da server.
  • Tutto sul dispositivo: i dati restano locali, sempre.

2

Inserisci il codice

Puoi digitare il codice manualmente oppure usare la funzione Scansiona.

3

Salva e usa

Dopo il salvataggio la carta apparirà nell'elenco principale, pronta da aprire e mostrare.

Uso quotidiano

Come mostro una carta alla cassa?

Apri la carta dall'elenco principale. Nella schermata di dettaglio vedrai il codice in formato grande, così da poterlo far leggere più facilmente dal lettore.

Posso aumentare la luminosità dello schermo?

Sì. Nella schermata di dettaglio puoi regolare la luminosità. Nelle impostazioni puoi anche abilitare l'aumento automatico durante la visualizzazione della carta.

Come modifico una carta esistente?

Apri la carta e usa l'azione di modifica. Puoi cambiare nome, categoria, stato preferita, codice, immagini e campi extra.

Come imposto una carta come preferita?

Nella modifica carta attiva l'opzione Preferita. Le carte preferite possono essere individuate più rapidamente nell'elenco.

Campi extra

I campi extra servono per salvare informazioni aggiuntive legate a una carta, ad esempio:

  • data di scadenza
  • numero socio
  • note personalizzate
  • informazioni utili da ricordare

Per aggiungerli, entra nella modifica della carta e usa la sezione Campi extra.

Impostazioni

  • Schermo sempre visibile: quando mostri una carta, lo schermo non va in stand-by.
  • Aumenta luminosità: usa un livello di luminosità predefinito durante la visualizzazione delle carte. Se disabilitato, non sarà possibile impostare anche la luminosità per le singole carte.
  • Abilita riordino: permette di riordinare manualmente le carte trascinandole.
  • Raggruppa: mostra le carte divise per categorie invece che in un unico elenco.
  • Riordina categorie: consente di cambiare la posizione delle categorie tramite trascinamento (disponibile solo se il raggruppamento è attivo).
  • Preserva campi extra: mantiene i campi extra anche se non sono più utilizzati da nessuna carta. Se disattivato, i campi inutilizzati vengono eliminati automaticamente.

Backup e ripristino

Esporta backup crea un file .zip con i dati dell'app.

Importa backup permette di ripristinare i dati precedentemente esportati.

Dopo l'importazione è necessario chiudere completamente l'app e riaprirla. Alla riapertura l'app potrebbe chiudersi automaticamente: è normale. Aprendola nuovamente, il ripristino sarà completato.

Domande frequenti

L'app richiede una connessione Internet?

No. L'app funziona completamente offline: tutte le carte vengono salvate e gestite localmente sul dispositivo.

I miei dati vengono condivisi online?

No. Tutti i dati restano sul dispositivo e non vengono condivisi online. Questo comportamento è coerente con quanto indicato nella privacy policy.

Perché il lettore del negozio non legge il codice?
  • Aumenta la luminosità.
  • Controlla che il tipo di codice sia corretto.
  • Verifica che il numero inserito coincida con quello della carta reale.
  • Prova a mostrare una foto della carta originale se disponibile.
Posso riordinare le carte?

Sì. L'ordinamento standard tiene conto di più fattori: prima le carte preferite, poi quelle più usate e infine quelle aperte più di recente.

Se trascini manualmente una carta in una posizione specifica, quella carta userà un ordine personalizzato che ha priorità sull'ordinamento automatico.

Quando vuoi tornare al comportamento normale, puoi usare l'opzione Riordina, che rimuove la posizione manuale salvata.

Official Help

Lite Card Wallet eXpress

Quick guide to add, manage and show your loyalty cards in a simple way. Here you can find the main features, the most common questions and useful notes.

Why this app was created

Lite Card Wallet eXpress was created with a simple idea: offer a card wallet that is lightweight, private and free from complications.

  • No account: no registration required.
  • No ads: a clean experience without distractions.
  • Free: all features are available at no cost.
  • No external services: no cloud and no server dependencies.
  • Everything stays on your device: data remains local at all times.

What you can do

  • Save cards with barcode or QR code.
  • Organize them by category and manage their order.
  • Mark cards as favorites.
  • Add custom fields such as expiration dates or notes.
  • Export and import a local backup.

Getting started

1

Add a card

From your wallet, tap the + button to create a new card.

2

Enter the code

You can type the code manually or use the Scan function.

3

Save and use it

After saving, the card will appear in the main list, ready to be opened and shown.

Daily use

How do I show a card at checkout?

Open the card from the main list. In the detail screen you will see the code in a large format, making it easier for the scanner to read.

Can I increase screen brightness?

Yes. In the card detail screen you can adjust brightness. In settings you can also enable automatic brightness increase while showing a card.

How do I edit an existing card?

Open the card and use the edit action. You can change the name, category, favorite status, code, images and extra fields.

How do I mark a card as favorite?

In the card edit screen, enable the Favorite option. Favorite cards can be found more quickly in the list.

Extra fields

Extra fields let you save additional information related to a card, for example:

  • expiration date
  • member number
  • custom notes
  • useful information to remember

To add them, open card editing and use the Extra fields section.

Settings

  • Keep screen on: while you are showing a card, the screen will not go into standby.
  • Increase brightness: uses a default brightness level while showing cards. If disabled, you will not be able to set brightness for individual cards either.
  • Enable reorder: lets you manually reorder cards by dragging them.
  • Group: shows cards by category instead of displaying everything in a single list.
  • Reorder categories: lets you change category positions by dragging them (available only when grouping is enabled).
  • Preserve extra fields: keeps extra fields even if they are no longer used by any card. If disabled, unused fields are automatically removed.

Backup and restore

Export backup creates a .zip file containing the app data.

Import backup restores data that was previously exported.

After importing, you need to fully close the app and open it again. When reopened, the app may close automatically: this is normal. Open it once more and the restore process will be completed.

Frequently asked questions

Does the app require an internet connection?

No. The app works completely offline: all cards are saved and managed locally on the device.

Are my data shared online?

No. All data stays on the device and is not shared online. This behavior is consistent with the privacy policy.

Why doesn't the store scanner read the code?
  • Increase brightness.
  • Check that the code type is correct.
  • Make sure the entered number matches the original card.
  • Try showing a photo of the original card if available.
Can I reorder my cards?

Yes. The default sorting takes multiple factors into account: favorite cards first, then the most used cards, and then the most recently opened ones.

If you manually drag a card to a specific position, that card will use a custom order, which takes priority over automatic sorting.

When you want to return to the normal behavior, use the Reorder option to remove the saved manual position.
