2. Information We Process

LCWX is designed to operate primarily with data stored locally on the user's device. The application may process the following information:

  • Card names entered by the user
  • Barcode or QR code values scanned or manually entered
  • Optional images or logos associated with cards
  • Temporary technical data required to perform barcode scanning

3. Camera Access

LCWX requires access to the device camera solely for scanning barcodes and QR codes.

Camera access is used in real time and no images or videos are recorded, stored, or transmitted to external servers.

4. Application Permissions

LCWX may request certain device permissions only to provide its features.

  • Camera
    Used exclusively for scanning barcodes and QR codes.
  • Photos / Files (optional)
    Used only when the user chooses an image or logo for a card, or uses import/export features.

LCWX does not access device data without user interaction or explicit permission.

5. Data Storage

All card information is stored locally on the user's device using local application storage and a SQLite database.

LCWX does not require user accounts and does not synchronize data with external servers in its current version.

6. Purpose of Data Processing

Data is processed solely to provide the following functionality:

  • Scanning barcodes and QR codes
  • Saving and organizing user cards
  • Displaying stored card codes when needed
  • Associating optional images or logos with cards
  • Allowing users to back up, export, import, and transfer their data manually

7. Data Sharing

LCWX does not sell, rent, or share user data with third parties.

The application does not include advertising platforms, marketing services, or user profiling tools.

8. Data Retention

All data remains on the device until the user decides to remove it.

  • Cards can be deleted within the application
  • Associated images can be removed
  • Exported backup files remain where the user saves them until the user removes them
  • Uninstalling the application removes locally stored data according to the operating system behavior

9. Data Import and Export

LCWX may provide optional features that allow users to export their data for backup or transfer purposes and to import previously exported data.

Exported data may be packaged as a ZIP archive that can contain the local SQLite database and any images or logos associated with saved cards.

Import and export operations are initiated manually by the user. LCWX does not automatically transmit exported files to external servers or third parties.

Once exported, the storage, sharing, and protection of the ZIP archive depend on the user and the services or applications used to manage the file.

10. Security

LCWX stores card data locally on the user's device. The application does not implement additional authentication or encryption mechanisms beyond those provided by the operating system.

The security of stored data therefore depends on device security features such as screen lock, biometrics, and operating system encryption.

If the user exports data, the user is responsible for deciding how and where the exported ZIP archive is stored or shared.

11. Data Loss Disclaimer

LCWX stores user data locally on the device. While reasonable efforts may be made to ensure the reliability of the application, no guarantee is provided regarding the preservation, availability, or recovery of user data.

Users are responsible for maintaining backups of their data using the export functionality provided by the application.

LCWX – Lite Card Wallet eXpress and its developer shall not be held liable for any loss of data resulting from device failure, software errors, accidental deletion, import/export issues, corrupted files, or other circumstances beyond reasonable control.

12. Tracking and Analytics

LCWX does not track users across apps or websites and does not use advertising identifiers.

The application does not include analytics, profiling, or user tracking technologies in its current version.

13. Children

LCWX is not specifically directed to children and does not knowingly collect personal information from children.

14. Third-Party Libraries

LCWX may use third-party software libraries required for technical functionality, such as barcode scanning, local database management, ZIP creation, file access, or user interface components.

These libraries are used solely to provide app functionality and not for advertising, tracking, or analytics purposes.

Updates will be published on this page together with the revised "Last updated" date.

2. Dati trattati

LCWX è progettata per funzionare principalmente con dati salvati localmente sul dispositivo dell'utente. L'applicazione può trattare le seguenti informazioni:

  • Nomi delle carte inseriti dall'utente
  • Codici a barre o QR code acquisiti tramite scansione o inserimento manuale
  • Immagini o loghi opzionali associati alle carte
  • Dati tecnici temporanei necessari per eseguire la scansione

3. Accesso alla fotocamera

LCWX richiede l'accesso alla fotocamera del dispositivo esclusivamente per la scansione di codici a barre e QR code.

La fotocamera viene utilizzata in tempo reale e nessuna immagine o video viene registrato, salvato o trasmesso a server esterni.

4. Permessi dell'applicazione

LCWX può richiedere alcuni permessi del dispositivo esclusivamente per fornire le proprie funzionalità.

  • Fotocamera
    Utilizzata esclusivamente per la scansione di codici a barre e QR code.
  • Foto / File (opzionale)
    Utilizzati solo quando l'utente sceglie un'immagine o un logo per una carta, oppure usa le funzioni di importazione/esportazione.

LCWX non accede ai dati del dispositivo senza interazione dell'utente o senza consenso esplicito.

5. Memorizzazione dei dati

Tutte le informazioni relative alle carte vengono memorizzate localmente sul dispositivo dell'utente tramite archiviazione locale dell'applicazione e database SQLite.

LCWX non richiede account utente e non sincronizza i dati con server esterni nella versione attuale.

6. Finalità del trattamento

I dati vengono trattati esclusivamente per fornire le seguenti funzionalità:

  • Scansione di codici a barre e QR code
  • Salvataggio e organizzazione delle carte dell'utente
  • Visualizzazione dei codici salvati quando necessario
  • Associazione di immagini o loghi opzionali alle carte
  • Consentire all'utente di eseguire manualmente backup, esportazione, importazione e trasferimento dei dati

7. Condivisione dei dati

LCWX non vende, non concede in uso e non condivide i dati dell'utente con terze parti.

L'applicazione non include piattaforme pubblicitarie, servizi di marketing o strumenti di profilazione dell'utente.

8. Conservazione dei dati

Tutti i dati rimangono sul dispositivo fino a quando l'utente decide di rimuoverli.

  • Le carte possono essere eliminate all'interno dell'applicazione
  • Le immagini associate possono essere rimosse
  • I file di backup esportati rimangono dove l'utente decide di salvarli fino alla loro eventuale rimozione
  • La disinstallazione dell'applicazione rimuove i dati memorizzati localmente secondo il comportamento del sistema operativo

9. Importazione ed esportazione dei dati

LCWX può offrire funzionalità opzionali che consentono all'utente di esportare i propri dati per finalità di backup o trasferimento e di importare dati precedentemente esportati.

I dati esportati possono essere raccolti in un archivio ZIP che può contenere il database SQLite locale e le eventuali immagini o loghi associati alle carte salvate.

Le operazioni di importazione ed esportazione vengono avviate manualmente dall'utente. LCWX non trasmette automaticamente i file esportati a server esterni o a terze parti.

Una volta esportato, il salvataggio, la condivisione e la protezione dell'archivio ZIP dipendono dall'utente e dai servizi o dalle applicazioni utilizzati per gestire tale file.

10. Sicurezza

LCWX salva i dati delle carte localmente sul dispositivo dell'utente. L'applicazione non implementa meccanismi aggiuntivi di autenticazione o cifratura oltre a quelli forniti dal sistema operativo.

La sicurezza dei dati memorizzati dipende quindi dalle funzionalità di sicurezza del dispositivo, come blocco schermo, biometria e cifratura del sistema operativo.

Se l'utente esporta i dati, è sua responsabilità decidere come e dove l'archivio ZIP esportato venga salvato o condiviso.

LCWX memorizza i dati dell'utente localmente sul dispositivo. Sebbene possano essere adottate misure ragionevoli per garantire l'affidabilità dell'applicazione, non viene fornita alcuna garanzia in merito alla conservazione, disponibilità o possibilità di recupero dei dati dell'utente.

L'utente è responsabile della creazione di copie di backup dei propri dati utilizzando la funzione di esportazione disponibile nell'applicazione.

LCWX – Lite Card Wallet eXpress e il suo sviluppatore non possono essere ritenuti responsabili per eventuali perdite di dati dovute a guasti del dispositivo, errori software, cancellazioni accidentali, problemi di importazione/esportazione, file corrotti o altre circostanze al di fuori del ragionevole controllo dello sviluppatore.

12. Tracciamento e analytics

LCWX non traccia gli utenti tra app o siti web e non utilizza identificatori pubblicitari.

L'applicazione non include analytics, profilazione o tecnologie di tracciamento dell'utente nella versione attuale.
