LCWX – Lite Card Wallet eXpress

Política de Privacidade

Última atualização: 30 de março de 2026

1. Controlador dos dados

O controlador dos dados do LCWX – Lite Card Wallet eXpress é:

Domenico Ciavarella
Email: lcwx@mclink.it

2. Informações que processamos

O LCWX foi projetado para operar principalmente com dados armazenados localmente no dispositivo do usuário. O aplicativo pode processar as seguintes informações:

  • Nomes dos cartões inseridos pelo usuário
  • Valores de código de barras ou QR code escaneados ou digitados manualmente
  • Imagens ou logos opcionais associados aos cartões
  • Dados técnicos temporários necessários para realizar a leitura

3. Acesso à câmera

O LCWX requer acesso à câmera do dispositivo exclusivamente para a leitura de códigos de barras e QR codes.

O acesso à câmera é usado em tempo real e nenhuma imagem ou vídeo é gravado, armazenado ou transmitido para servidores externos.

4. Permissões do aplicativo

O LCWX pode solicitar determinadas permissões do dispositivo apenas para fornecer seus recursos.

  • Câmera
    Usada exclusivamente para leitura de códigos de barras e QR codes.
  • Fotos / Arquivos (opcional)
    Usados somente quando o usuário escolhe uma imagem ou logo para um cartão, ou utiliza recursos de importação/exportação.

O LCWX não acessa dados do dispositivo sem interação do usuário ou permissão explícita.

5. Armazenamento de dados

Todas as informações dos cartões são armazenadas localmente no dispositivo do usuário usando o armazenamento local do aplicativo e um banco de dados SQLite.

O LCWX não exige contas de usuário e não sincroniza dados com servidores externos em sua versão atual.

6. Finalidade do tratamento de dados

Os dados são processados apenas para fornecer a seguinte funcionalidade:

  • Leitura de códigos de barras e QR codes
  • Salvar e organizar os cartões do usuário
  • Exibir códigos de cartões salvos quando necessário
  • Associar imagens ou logos opcionais aos cartões
  • Permitir que os usuários façam backup, exportem, importem e transfiram seus dados manualmente

7. Compartilhamento de dados

O LCWX não vende, aluga nem compartilha dados do usuário com terceiros.

O aplicativo não inclui plataformas de publicidade, serviços de marketing ou ferramentas de perfilamento do usuário.

8. Retenção de dados

Todos os dados permanecem no dispositivo até que o usuário decida removê-los.

  • Os cartões podem ser excluídos dentro do aplicativo
  • As imagens associadas podem ser removidas
  • Os arquivos de backup exportados permanecem onde o usuário os salvar até que sejam removidos
  • A desinstalação do aplicativo remove os dados armazenados localmente de acordo com o comportamento do sistema operacional

9. Importação e exportação de dados

O LCWX pode oferecer recursos opcionais que permitem aos usuários exportar seus dados para fins de backup ou transferência e importar dados exportados anteriormente.

Os dados exportados podem ser empacotados como um arquivo ZIP que pode conter o banco de dados SQLite local e quaisquer imagens ou logos associados aos cartões salvos.

As operações de importação e exportação são iniciadas manualmente pelo usuário. O LCWX não transmite automaticamente os arquivos exportados para servidores externos ou terceiros.

Depois de exportado, o armazenamento, compartilhamento e proteção do arquivo ZIP dependem do usuário e dos serviços ou aplicativos usados para gerenciar o arquivo.

10. Segurança

O LCWX armazena os dados dos cartões localmente no dispositivo do usuário. O aplicativo não implementa mecanismos adicionais de autenticação ou criptografia além daqueles fornecidos pelo sistema operacional.

A segurança dos dados armazenados depende, portanto, dos recursos de segurança do dispositivo, como bloqueio de tela, biometria e criptografia do sistema operacional.

Se o usuário exportar dados, cabe a ele decidir como e onde o arquivo ZIP exportado será armazenado ou compartilhado.

11. Isenção de responsabilidade por perda de dados

O LCWX armazena os dados do usuário localmente no dispositivo. Embora possam ser feitos esforços razoáveis para garantir a confiabilidade do aplicativo, nenhuma garantia é fornecida quanto à preservação, disponibilidade ou recuperação dos dados do usuário.

Os usuários são responsáveis por manter backups de seus dados usando a funcionalidade de exportação fornecida pelo aplicativo.

O LCWX – Lite Card Wallet eXpress e seu desenvolvedor não poderão ser responsabilizados por qualquer perda de dados resultante de falha do dispositivo, erros de software, exclusão acidental, problemas de importação/exportação, arquivos corrompidos ou outras circunstâncias além de um controle razoável.

12. Rastreamento e análises

O LCWX não rastreia usuários entre aplicativos ou sites e não utiliza identificadores de publicidade.

O aplicativo não inclui tecnologias de análise, perfilamento ou rastreamento do usuário em sua versão atual.

13. Verificação de atualizações do aplicativo

O LCWX pode realizar uma conexão com a Internet exclusivamente para verificar se há uma nova versão do aplicativo disponível.

Essa verificação é feita por meio do download de um arquivo remoto simples (por exemplo, JSON) contendo informações sobre a versão mais recente disponível.

  • nenhum dado pessoal é coletado
  • nenhum dado do usuário é transmitido
  • nenhum rastreamento é realizado

A verificação é realizada apenas ocasionalmente e não de forma contínua.

A conexão é usada apenas para informar o usuário sobre atualizações disponíveis e, se necessário, redirecioná-lo para a loja para atualizar o aplicativo.

14. Crianças

O LCWX não é direcionado especificamente a crianças e não coleta conscientemente informações pessoais de crianças.

15. Bibliotecas de terceiros

O LCWX pode usar bibliotecas de software de terceiros necessárias para a funcionalidade técnica, como leitura de código de barras, gerenciamento de banco de dados local, criação de arquivos ZIP, acesso a arquivos ou componentes de interface do usuário.

Essas bibliotecas são usadas exclusivamente para fornecer a funcionalidade do aplicativo e não para fins de publicidade, rastreamento ou análises.

16. Alterações nesta política

Esta Política de Privacidade pode ser atualizada periodicamente para refletir alterações técnicas, legais ou funcionais do aplicativo.

As atualizações serão publicadas nesta página junto com a data revisada de "Última atualização".
