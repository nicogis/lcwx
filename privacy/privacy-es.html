LCWX – Lite Card Wallet eXpress

Política de Privacidad

Última actualización: 11 de marzo de 2026

1. Responsable del tratamiento

El responsable del tratamiento de los datos para LCWX – Lite Card Wallet eXpress es:

Domenico Ciavarella
Email: lcwx@mclink.it

2. Información que procesamos

LCWX está diseñada para funcionar principalmente con datos almacenados localmente en el dispositivo del usuario. La aplicación puede procesar la siguiente información:

  • Nombres de tarjetas introducidos por el usuario
  • Valores de códigos de barras o códigos QR escaneados o introducidos manualmente
  • Imágenes o logotipos opcionales asociados a las tarjetas
  • Datos técnicos temporales necesarios para realizar el escaneo

3. Acceso a la cámara

LCWX requiere acceso a la cámara del dispositivo únicamente para escanear códigos de barras y códigos QR.

El acceso a la cámara se utiliza en tiempo real y no se graban, almacenan ni transmiten imágenes o vídeos a servidores externos.

4. Permisos de la aplicación

LCWX puede solicitar determinados permisos del dispositivo solo para proporcionar sus funciones.

  • Cámara
    Se utiliza exclusivamente para escanear códigos de barras y códigos QR.
  • Fotos / Archivos (opcional)
    Se utilizan solo cuando el usuario elige una imagen o logotipo para una tarjeta, o usa las funciones de importación/exportación.

LCWX no accede a los datos del dispositivo sin interacción del usuario o sin permiso explícito.

5. Almacenamiento de datos

Toda la información de las tarjetas se almacena localmente en el dispositivo del usuario mediante almacenamiento local de la aplicación y una base de datos SQLite.

LCWX no requiere cuentas de usuario y no sincroniza datos con servidores externos en su versión actual.

6. Finalidad del tratamiento

Los datos se procesan únicamente para proporcionar la siguiente funcionalidad:

  • Escaneo de códigos de barras y códigos QR
  • Guardar y organizar las tarjetas del usuario
  • Mostrar los códigos guardados cuando sea necesario
  • Asociar imágenes o logotipos opcionales a las tarjetas
  • Permitir a los usuarios realizar copias de seguridad, exportar, importar y transferir manualmente sus datos

7. Cesión de datos

LCWX no vende, alquila ni comparte datos de usuario con terceros.

La aplicación no incluye plataformas publicitarias, servicios de marketing ni herramientas de elaboración de perfiles.

8. Conservación de datos

Todos los datos permanecen en el dispositivo hasta que el usuario decida eliminarlos.

  • Las tarjetas pueden eliminarse dentro de la aplicación
  • Las imágenes asociadas pueden eliminarse
  • Los archivos de copia exportados permanecen donde el usuario los guarde hasta que los elimine
  • La desinstalación de la aplicación elimina los datos almacenados localmente según el comportamiento del sistema operativo

9. Importación y exportación de datos

LCWX puede ofrecer funciones opcionales que permiten a los usuarios exportar sus datos con fines de copia de seguridad o transferencia e importar datos exportados previamente.

Los datos exportados pueden empaquetarse como un archivo ZIP que puede contener la base de datos SQLite local y cualquier imagen o logotipo asociado a las tarjetas guardadas.

Las operaciones de importación y exportación se inician manualmente por el usuario. LCWX no transmite automáticamente los archivos exportados a servidores externos ni a terceros.

Una vez exportado, el almacenamiento, uso compartido y protección del archivo ZIP dependen del usuario y de los servicios o aplicaciones utilizados para gestionar el archivo.

10. Seguridad

LCWX almacena los datos de las tarjetas localmente en el dispositivo del usuario. La aplicación no implementa mecanismos adicionales de autenticación o cifrado más allá de los proporcionados por el sistema operativo.

La seguridad de los datos almacenados depende, por tanto, de las funciones de seguridad del dispositivo, como el bloqueo de pantalla, la biometría y el cifrado del sistema operativo.

Si el usuario exporta datos, es responsabilidad suya decidir cómo y dónde se almacena o comparte el archivo ZIP exportado.

11. Exención de responsabilidad por pérdida de datos

LCWX almacena los datos del usuario localmente en el dispositivo. Aunque pueden realizarse esfuerzos razonables para garantizar la fiabilidad de la aplicación, no se ofrece ninguna garantía respecto a la conservación, disponibilidad o recuperación de los datos del usuario.

Los usuarios son responsables de mantener copias de seguridad de sus datos utilizando la funcionalidad de exportación proporcionada por la aplicación.

LCWX – Lite Card Wallet eXpress y su desarrollador no serán responsables de ninguna pérdida de datos derivada de fallos del dispositivo, errores de software, eliminación accidental, problemas de importación/exportación, archivos corruptos u otras circunstancias fuera de un control razonable.

12. Seguimiento y analíticas

LCWX no rastrea a los usuarios entre aplicaciones o sitios web y no utiliza identificadores publicitarios.

La aplicación no incluye tecnologías de analítica, elaboración de perfiles o seguimiento del usuario en su versión actual.

13. Comprobación de actualizaciones de la aplicación

LCWX puede realizar una conexión a Internet únicamente para comprobar si hay una versión más reciente de la aplicación disponible.

Esta comprobación se realiza descargando un archivo remoto simple (por ejemplo, JSON) que contiene información sobre la última versión disponible.

  • no se recopilan datos personales
  • no se transmiten datos del usuario
  • no se realiza ningún seguimiento

La comprobación se realiza solo de forma ocasional y no continua.

La conexión se utiliza únicamente para informar al usuario sobre las actualizaciones disponibles y, si es necesario, redirigirlo a la tienda para actualizar la aplicación.

14. Menores

LCWX no está dirigida específicamente a menores y no recopila conscientemente información personal de menores.

15. Bibliotecas de terceros

LCWX puede utilizar bibliotecas de software de terceros necesarias para la funcionalidad técnica, como escaneo de códigos de barras, gestión de bases de datos locales, creación de archivos ZIP, acceso a archivos o componentes de interfaz de usuario.

Estas bibliotecas se utilizan únicamente para proporcionar la funcionalidad de la aplicación y no con fines de publicidad, seguimiento o analítica.

16. Cambios en esta política

Esta Política de Privacidad puede actualizarse periódicamente para reflejar cambios técnicos, legales o funcionales de la aplicación.

Las actualizaciones se publicarán en esta página junto con la fecha revisada de "Última actualización".
